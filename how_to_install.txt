## Installation Instructions

### Step 1: Install Inno Setup
1. Download from: https://jrsoftware.org/isdl.php
2. Install Inno Setup 6 (latest version)
3. Add to PATH or note installation location

### Step 2: Build the Executable
```bash
# Build with PyInstaller first
pyinstaller --onefile --windowed --name "BybitDataFetcher" --hidden-import pandas --hidden-import pybit --hidden-import numpy main.py
Step 3: Create Documentation Files
bash
# Create required files
echo. > README.md
echo. > LICENSE.txt
echo. > CHANGELOG.txt
mkdir scripts
Step 4: Build the Installer
bash
# Run the build script
build_installer.bat

# Or manually with Inno Setup
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
Step 5: Test the Installer
Run the generated BybitDataFetcher_Setup.exe

Follow installation wizard

Verify installation works correctly

Test uninstallation
